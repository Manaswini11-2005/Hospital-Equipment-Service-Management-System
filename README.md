Hospital Equipment Service Management System
Python, Django, HTML, CSS, SQLite

- Developed a web-based application to manage hospital equipment records and streamline technical service requests.
- Implemented CRUD operations to register equipment, create service tickets, update issue details, and maintain resolution records.
- Designed a ticket management workflow to track issue priorities, assign support personnel, and monitor ticket statuses.
- Integrated Django models and SQLite database to store and manage equipment and service-related information.
- Built user-friendly web pages using HTML and CSS with Django authentication for controlled application access.
